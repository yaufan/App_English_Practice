# 英文練習

自己用的英文練習 App（Android）。

- **口說對話**：12 個情境（日常、AI 工作、多益／雅思口說）加自由聊天。用語音跟手機上的離線 AI 對話，每句可看中文、慢速重播，卡住可以看提示，每講一句會給更自然的說法，結束後整理檢討。
- **單字片語**：日常會話、AI 工作用語、多益核心單字各 60 個，加上自己收藏的句子。間隔複習，可以翻卡或用說的。
- **聽力**：12 篇內建短文，也能請 AI 依主題產生。可以調速度、逐句播放、中英對照、聽寫、做題目。

## 安裝
到 [Releases](../../releases/latest) 下載 `english-practice.apk`，或用手機掃 Release 頁的 QR code。第一次安裝要允許「安裝不明來源的應用程式」。

## 第一次使用
1. 打開「設定」→「離線 AI 模型」，用 Wi-Fi 下載模型（標準約 1.3 GB，輕量約 0.5 GB），下載完按「測試模型」。之後 AI 都在手機上執行，不用網路也不用金鑰。
2. 語音辨識需要手機有 Google 語音服務（大部分 Android 手機都有）。第一次按麥克風時允許麥克風權限。

## 開發
```bash
npm ci
npx tsc --noEmit
npm test
```
push 到 `main` 會自動打包 APK 並發布到 Releases。
